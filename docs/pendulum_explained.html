振り子モデルの解剖

XML に 8 行書いただけの棒が、なぜあの周期で揺れるのか。 MJCF の記述・物理量・運動方程式・位相平面が、どう1つに繋がっているかを図で追う。

01

XML に書いたものと、MuJoCo が計算したもの

あなたが書いたのは形状だけ。質量・重心・慣性モーメントは、 そこから MuJoCo が導いている。この「書いた値」と「導かれた値」の区別が出発点。

自分の環境で確認する

下のコードで、上の図の数値が本当にモデルに入っているか確かめられる。 図の値はカプセル形状から手計算した概算なので、あなたのモデルの実際の値と数％ずれることがある。 信じるべきは print した値のほう。

# body の物理量を読み出す
bid = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_BODY, "pole")
print("mass    ", model.body_mass[bid])     # 質量
print("com     ", model.body_ipos[bid])     # 重心位置 → [0, 0, -0.25]
print("inertia ", model.body_inertia[bid])  # 主慣性モーメント（重心まわり）
print("iquat   ", model.body_iquat[bid])    # [1,0,0,0] なら主軸 = body 座標系
02

なぜ d であって L ではないのか

重力は重心にかかる。回転軸から重心までの距離が、てこの腕の長さになる。

理想の単振り子今回の剛体棒（物理振子）
質量の分布先端に一点集中棒全体に均等
重心までの距離 dLL / 2 = 0.25 m
慣性モーメント Im·L²≈ m·L²/3
周期T = 2π√(L/g)T = 2π√(I/(m·g·d))

右の式に理想の単振り子の値（I = mL², d = L）を代入すると T = 2π√(L/g) に戻る。単振り子の式は物理振子の式の特殊ケースであり、 質量が分布した棒には使えない。1-4 のヒントで「そのまま当てるとズレる」と書いたのはこの意味。

04

位相平面の読み方

横軸に角度、縦軸に角速度を取った平面。振り子の「状態」がこの平面上の 1 点で表される。 Step 4 のスイングアップ、Step 5 の状態空間の議論は、すべてこの図の上で行われる。

  • 点が時計回りに 1 周すると、振り子が 1 往復したことになる
  • 楕円が大きいほどエネルギーが高い。振幅も最高速度も大きい
  • Step 4 のエネルギー整形とは、モータで少しずつエネルギーを注入して、楕円を外側へ広げていく操作にほかならない。倒立状態は、この平面上の特別な 1 点として現れる
